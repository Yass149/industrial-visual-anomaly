# Figure attribution

`bottle-overlay.png` and `screw-false-negatives.png` are diagnostic adaptations of MVTec AD
images: resized/cropped images with model heatmaps and, for error grids, mask contours.
Original dataset: Paul Bergmann, Michael Fauser, David Sattlegger and Carsten Steger,
**MVTec AD — A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection**, CVPR 2019.
Source: https://www.mvtec.com/research-teaching/datasets/mvtec-ad

These image adaptations are provided under the dataset's Creative Commons
Attribution-NonCommercial-ShareAlike 4.0 International licence:
https://creativecommons.org/licenses/by-nc-sa/4.0/

`cost-sensitivity.png` is a plot of this project's measured calibration results.
No raw dataset archive or training/test image collection is included in the repository.
